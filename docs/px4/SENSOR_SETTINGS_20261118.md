| 水平视场 | 360°（−π～+π） |

| 每帧上限 | 16×1800＝28,800 次射线测量；输出有效点数受过滤与场景影响 |
| 量程 | 0.3～100 m |
| SDF 距离分辨率 | 0.001 m，不能当成测量精度 |
| SDF 测距噪声配置 | 零均值高斯噪声，标准差 0.02 m；当前 ROS 点云插件绕过此层，不能视为输出已加噪 |
| ROS 插件额外噪声 | 0；当前输出未获得上述 0.02 m 随机测距噪声 |
| 安装 | 相对 `base_link` 平移 `(0,0,+0.15)` m，默认姿态一致、水平安装 |
| 话题 | `/velodyne_points_raw` → `/velodyne_points`；适配后为 `/msim/velodyne_points_annotated` |
| 坐标帧 | `velodyne` |

原始 PointCloud2 包含 `x/y/z/intensity`。Velodyne 入口适配器从垂直角度恢复 `ring=0…15`，每点 `time=1e-6 s`。这表示同一时刻的快照，不是完整旋转扫描的真实逐点时间。当前未模拟材质相关强度、多回波、雨雾、遮挡概率丢点或真实旋转扫描的运动畸变。

2026-11-19 核查更正：`gazebo_ros_block_laser` 直接读取 `LaserShape()->GetRange()`，而 Gazebo `RaySensor` 的 SDF 噪声在生成其 scan 消息时才施加；插件自己的 `gaussianNoise` 又被设为 0。因此“已配置 0.02 m”不等于 ROS 点云已获得该噪声。已有无欺骗录包仿真时间 2.202～2.902 s 连续 8 帧、每帧 28,023 个有效点逐点完全相同，支持此判断。详见 [传感器真实性核查](SENSOR_REALISM_AUDIT_20261119.md)。

FAST-LIO 本轮设置 `point_filter_num=4` 是算法抽稀，不会把传感器的水平采样数从 1800 改小；LIGO 与 LIO-SAM 使用各自的算法预处理参数。

## LiDAR/IMU 算法使用的 ROS IMU

安装在 `base_link` 原点，与机体坐标轴一致。Gazebo `/imu/ideal` 经过独立误差模型得到 `/imu/data`；测量包括角速度、比力和姿态四元数。

| 参数（每轴） | 陀螺仪 | 加速度计 |
| --- | ---: | ---: |
| 连续白噪声密度 | 8.726646×10⁻⁴ rad/s/√Hz（约 0.05°/s/√Hz） | 0.00637 m/s²/√Hz |
| 开机零偏标准差 | 0.0017453293 rad/s（约 0.1°/s） | 0.02 m/s² |
| 零偏随机驱动强度（表示零偏随时间随机变化的快慢，数值越大，零偏漂移越快） | 2×10⁻⁵ (rad/s)/√s | 2×10⁻⁴ (m/s²)/√s |
| 零偏相关时间（零偏变化的时间尺度，经过该时间后相关性约降至初始值的 1/e） | 1000 s | 300 s |

零偏按一阶相关过程演化，包含开机随机零偏和随时间变化的偏置；不是恒定为零。固定随机种子为 `20261115`。标称频率 200 Hz，当前录包实测约 166.6 Hz，中位时间间隔 6 ms。

单样本白噪声标准差按 `噪声密度 / sqrt(实际 Δt)` 计算，协方差分别填写陀螺仪与加速度计的白噪声方差，不包含本次运行中未知零偏的方差。上述零偏随机驱动强度也可分别写为 `rad/s²/√Hz`、`m/s³/√Hz`。

| 姿态误差设置（每轴） | 数值 |
| --- | ---: |
| 初始姿态误差标准差 | 0.3° |
| 每帧姿态白噪声标准差 | 0.05° |
| 姿态随机漂移强度 | 0.02°/√s |

姿态四元数由 Gazebo 姿态加误差后归一化产生，并非由这套带噪声角速度、加速度和磁力计实时解算的 AHRS。LIO-SAM 会使用此姿态信息；FAST-LIO/LIGO 并不使用完全相同的姿态约束。当前未额外模拟 IMU 温漂、比例因子、轴间不正交、振动或饱和。

## PX4 飞控使用的 IMU

PX4 原生 IMU 插件输出 Gazebo Transport `/imu`，安装在机体上方 0.02 m；ROS `/imu/data` 与它是两条独立数据链路。两套 IMU 的陀螺仪/加速度计噪声密度、开机零偏、零偏驱动强度及相关时间设为相同量级，但随机样本独立。PX4 插件随物理更新发布，不应将 ROS IMU 实测的 166.6 Hz 当作 PX4 IMU 的实际输出率。

| 项目 | 设置 |
| --- | --- |
| 当前实验输入 | Gazebo 机体真值加天线杆臂，再叠加指定位置偏移 |
| 更新频率 | 5 Hz，录包实测 5 Hz |
| 天线杆臂 | 相对机体 `(0.05,0,0.04)` m，随姿态旋转到世界系 |
| 地理原点 | 纬度 30.5312°，经度 114.3601°，海拔 50 m，局部 ENU |
| PX4 输入 | MAVLink `HIL_GPS`；在线模式移除原生 Gazebo GPS，避免双输入 |
| 定位类型／卫星数 | 3D fix／16 |
| ROS 位置话题 | `/msim/spoofed_gnss_odom`，`msim_enu` 坐标帧 |
| ROS 报告的位置方差 | 东、北各 0.49 m²；天向 4.0 m² |
| 无欺骗组 | 无附加固定偏移和欺骗漂移，也未额外采样随机定位噪声 |
| 有欺骗组 | 相对注入源启动 20 s 后，向东按 0.18 m/s 增加位置偏移；北向、天向不增加欺骗偏移 |

报告方差不是实际叠加了对应幅度的随机位置噪声。当前欺骗仅修改位置；`HIL_GPS` 中的速度仍由真实天线运动计算，未同步叠加欺骗漂移速度。它是位置级实验输入，尚非伪距、载波、多普勒或射频欺骗。在线 GPS 尚未由 SignalSim/RTKLIB 观测实时解算，建筑也不会自动改变此位置源的多路径或遮挡误差。

## 仿真时间与实测频率

物理步长 0.002 s，目标物理更新率 500 Hz，重力 9.80665 m/s²。ROS 算法与传感器使用 Gazebo `/clock` 仿真时间；运行负载可能改变实际墙钟耗时。在线检测器允许 IMU 年龄不超过 50 ms、LiDAR 年龄不超过 200 ms；其配对门禁不等同于纯 LIO 内部的 LiDAR/IMU 同步检查。

| 本轮源录包 | ROS IMU 实测 | LiDAR 实测 | GPS 实测 | 真值实测 |
| --- | ---: | ---: | ---: | ---: |
| 无欺骗 | 166.6505 Hz | 10.0 Hz | 5.0 Hz | 100.0 Hz |
| 有欺骗 | 166.6342 Hz | 10.0 Hz | 5.0 Hz | 100.0 Hz |

以上频率由消息头时间戳计算，非墙钟吞吐率。半速回放不会把传感器标称频率改成一半。传感器误差参数也不同于各算法内部的过程噪声、测量权重、体素滤波和点云抽稀参数。
