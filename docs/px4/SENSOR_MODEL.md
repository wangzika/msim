# PX4/Gazebo 传感器误差模型

生效配置为 [`sensor_profile.json`](../../adapters/ros1_noetic/msim_sensors/config/sensor_profile.json)。`tools/px4-uav-capture.sh` 每次生成 Iris SDF，并将本次配置复制到运行目录；用 `--sensor-profile /绝对路径/profile.json` 可运行独立参数组。修改 JSON 后必须重新采集。该配置是可复现的研究基线，尚未由特定实物传感器的静置数据或标定报告拟合。

## IMU：输入、单位和误差

Gazebo `msim_imu` 发布理想测量 `/imu/ideal`；`msim_imu_model` 发布 `/imu/data`，供 FAST_GLIO、LIO-SAM 和在线 GNSS 检测器使用。模型按各轴计算：

```text
角速度测量 = 真实角速度 + 陀螺仪零偏 + 陀螺仪白噪声
加速度测量 = 真实比力   + 加速度计零偏 + 加速度计白噪声
零偏下一步 = exp(-Δt/τ) × 当前零偏 + 相关随机扰动
单样本白噪声标准差 = 连续时间噪声密度 / sqrt(Δt)
```

`Δt` 取 ROS 消息的仿真时间戳差，不按墙钟时间。固定随机种子使相同时间序列可重现。下列参数为每轴参数；`rad/s/√Hz`、`m/s²/√Hz` 指连续时间白噪声密度，零偏随机游走的单位分别为 `rad/s²/√Hz` 和 `m/s³/√Hz`。

| 参数 | ROS IMU 当前值 | PX4 原生 IMU 当前值 |
|---|---:|---:|
| 陀螺仪噪声密度 | 0.0008726646 rad/s/√Hz | 同左 |
| 加速度计噪声密度 | 0.00637 m/s²/√Hz | 同左 |
| 陀螺仪开机零偏标准差 | 0.0017453293 rad/s | 同左 |
| 加速度计开机零偏标准差 | 0.02 m/s² | 同左 |
| 陀螺仪零偏随机游走 | 0.00002 rad/s²/√Hz | 同左 |
| 加速度计零偏随机游走 | 0.0002 m/s³/√Hz | 同左 |
| 陀螺仪／加速度计零偏相关时间 | 1000 s／300 s | 同左 |

ROS IMU 标称 200 Hz；PX4 原生插件按其仿真更新循环工作。两者误差量级一致，但硬件安装点和随机抽样不同：ROS IMU 在 `base_link` 原点，PX4 IMU 在 `base_link` 上方 0.02 m。`/imu/data` 的角速度、加速度协方差按**每帧实际时间间隔**和噪声密度分别计算；它们是测量白噪声协方差，不包含条件于本次运行的未知零偏方差。

ROS IMU 的姿态输出用 Gazebo 姿态加初始 0.3°、每帧 0.05° 和 0.02°/√s 的慢漂移来近似一个姿态解算器；误差以小角度四元数施加，输出归一化并填写相应协方差。这**仍不是**根据加速度计、陀螺仪和磁力计实际解算的 AHRS；评估依赖姿态四元数的算法时应单独说明。FAST-LIO 的 `acc_cov`、`gyr_cov` 和零偏协方差是滤波器参数，不能直接当作这里的硬件噪声值。

## LiDAR：几何与误差

当前采集默认使用独立的分时扫描插件，16 线、水平 360°、垂直 −15° 到 +15°、10 Hz，每圈 1800 个水平采样方向。量程 0.3～100 m；有效返回上叠加标准差 0.02 m 的径向高斯噪声，并进行 0.001 m 距离量化。可切换 32／64 线参数模型与快照对照模式，详见 [快速切换](SENSOR_SWITCHING.md)。

分时扫描在当前 2 ms 物理步长下分约 50 批求交，各点时间覆盖约 0～98 ms，点坐标属于各自采集时刻的雷达坐标系。Velodyne 入口直接使用原生 ring/time；不会再把分时扫描改成统一微小时间。快照模式和旧 XYZI 录包的格式适配仍使用统一微小时间。默认前端已切换为 Velodyne。

2026-11-19 之前的 block laser 链路曾绕过 SDF 的测距噪声，旧录包不能按 0.02 m 噪声解释；见 [核查记录](SENSOR_REALISM_AUDIT_20261119.md)。当前插件已经在实际输出径向距离上加噪，并通过解析房间测试验证。型号几何是均匀垂直角近似，未复现厂商逐束发射和反射强度标定、多回波、雨雾。

## GPS

当前保留原生 GPS 的噪声、偏差和约 120 ms 延迟，通过隔离话题中继增加正常接收机误差与在线攻击；正常与攻击测量成对记录，PX4 与组合使用同一受攻击样本。默认接收机误差包含一阶相关偏差与较小位置白噪声，参数、协方差、速度一致攻击及处理缓冲说明见 [传感器切换](SENSOR_SWITCHING.md)。[2026-11-18 设置](SENSOR_SETTINGS_20261118.md) 是旧配置快照，不代表升级后的新采集。

## 验证记录

2026-11-15 使用新配置做了 4 秒采集指令的短时 PX4/Gazebo 启动验证。录包有 `/imu/data` 945 条、`/velodyne_points` 56 帧；IMU 时间戳间隔中位数 0.006 s（约 167 Hz），雷达约 10 Hz，首帧有效点数 28,023。角速度与加速度协方差分别为约 `1.27e-4 (rad/s)²` 和 `6.76e-3 (m/s²)²`，四元数范数为 1。标称 IMU 200 Hz 与实际发布率之间的差异可能受 Gazebo 物理步长和 ROS 插件节流影响；做正式实验时应继续记录实际频率与间隔分布。

随后完成 28 秒的默认 GPS 短航线采集：录包含 4,944 条 IMU、296 帧 LiDAR；PX4 ULog 验证通过，飞机已解锁、进入 OFFBOARD，最大位移 20.86 m、爬升 8.15 m。这证明新误差配置没有阻断飞行和录包；尚未重新评估 FAST_GLIO 的定位精度或双窗口实时性能。
